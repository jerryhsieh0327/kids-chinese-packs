单元二巩固⑦：多义字·成语·仿写·修辞·段落大意（第3关） · 第 3 关 · 上海小学四年级

多义字：把加点字放回整词里想，不要只记一个常用义。
成语要贴合句子语境，别只挑「认识」的词；近义干扰项要细比。
「越……越……」写程度变化；「犹如」后面要接形象的比喻。
比喻常有「像／仿佛／犹如」；拟人是让物做人事。主修辞看整句核心。
段落大意抓这一段反复写的中心，别把别段内容硬套进来。

第1题 · 多义字「清」

读下面两句：①「盘古终于清醒过来」里的「清」；②「山涧的水又清又亮」里的「清」。下面哪一项对两处「清」的意思判断最准确？

  1. ①神志明白、不糊涂；②水纯净、不浑浊 ✔
  2. ①打扫干净；②水纯净、不浑浊
  3. ①神志明白、不糊涂；②声音清脆
  4. 两处都是「干净」的意思

答案: A

「清醒」的「清」＝神志明白、不糊涂；「水又清又亮」的「清」＝纯净、不浑浊。两处意思不同。

错项解析:
B: 「打扫干净」是「清扫／清除」一类义，不是「清醒」里的「清」。
C: ①对；但②写的是水色，不是「声音清脆」。
D: 两处「清」意思并不相同，不能一律当成「干净」。

第2题 · 成语选用

短文写盘古撑开天地后「精疲力竭」，终于倒下。若要选一个成语形容他「力气用尽、非常疲倦」的状态，下面哪个最贴切？注意：有的词写别的意思，不要混。

  1. 开天辟地
  2. 精疲力竭 ✔
  3. 枝繁叶茂
  4. 奔流不息

答案: B

「精疲力竭」正写精神、力气都用尽，极度疲倦，贴合盘古撑天力尽的状态。

错项解析:
A: 「开天辟地」写开创天地／前所未有，是全文主旨类，不是「累坏了」。
C: 「枝繁叶茂」写草木茂盛，跟疲倦无关。
D: 「奔流不息」常写水流不停，不是人累。

第3题 · 仿写相关判断

原句：「天越升越高，地越沉越厚，盘古的身体犹如一根顶天立地的柱子。」老师要求仿写必须同时保留：①「越……越……」写程度变化；②「犹如」后接形象比喻。下面哪一句最符合要求？

  1. 雨越下越大，路上的行人犹如一把把匆忙撑开的伞。 ✔
  2. 雨很大，行人很多，犹如我很害怕打湿鞋子。
  3. 雨越下越大，风也越来越猛，路上越来越滑。
  4. 雨大了，犹如一场仗，行人像跑一样。

答案: A

A 有「越……越……」写变化，又有「犹如」接「一把把匆忙撑开的伞」的形象比喻，两项都齐。

错项解析:
B: 「犹如」后接「我很害怕……」不是形象比喻，且缺少规范的「越……越……」程度变化。
C: 只有「越……越……」，没有「犹如」比喻。
D: 有「犹如」，但缺少「越……越……」的程度变化句式；后半也较散。

第4题 · 比喻还是拟人

「太阳像一盏温暖的灯，温柔地照亮刚刚分开的世界。」有同学说这是拟人，有同学说这是比喻。下面哪一项判断最合理？

  1. 主要是比喻：把太阳比作一盏灯，有「像」；「温柔地照亮」是顺着比喻写的。 ✔
  2. 只能是拟人：因为太阳「温柔」，物做了人事。
  3. 只能是夸张：世界一下子就亮了。
  4. 只能是排比：句子里有两个动作。

答案: A

句子核心是「像一盏温暖的灯」——把一物比作另一物，主修辞是比喻；「温柔」是顺着这个比喻写的，不宜只抓「温柔」就断定整句只能是拟人。

错项解析:
B: 「温柔」确有拟人色彩，但整句靠「像……」构成比喻，主修辞应看核心。
C: 虽有明亮感，但没有故意把程度说得过分到「夸张」为主。
D: 排比要有三个以上结构相似的短语或句子，这里没有。

第5题 · 画面感·感受

短文写：「混沌的宇宙像个大鸡蛋。盘古醒来，挥起大斧，只听咔嚓一声，轻而清的东西上升变成了天，重而浊的东西下降变成了地。」下面哪一句最像「阅读感受」（不是复述情节，也不是常识）？

  1. 宇宙一开始像鸡蛋，盘古用斧头把天地劈开了。
  2. 读到「咔嚓」那一声，我仿佛听见天地第一次分开，心里又紧张又兴奋。 ✔
  3. 这句话用了「像」和「变成」。
  4. 天在上、地在下，这是自然常识。

答案: B

「感受」要写出自己的心情、态度或体会；B 有紧张、兴奋，并连到文中的「咔嚓」画面。A 只是复述情节。

错项解析:
A: 这是「读到了什么／情节复述」，还缺少情感或态度。
C: 这是数用词，不是阅读感受。
D: 这是常识说明，不是读文后的感受。

第6题 · 段落大意 ⭐ 挑战题

一篇短文分三段：第1段写宇宙混沌，像个大鸡蛋，盘古在里面沉睡；第2段写他醒来后挥斧开天辟地，头顶天、脚踏地，身体不断长高；第3段写他倒下后，气息变成风云，声音变成雷霆，眼睛变成日月，四肢和身躯变成大地山川。问：第3段的主要意思是什么？

  1. 宇宙一开始混沌不明，盘古沉睡其中
  2. 盘古用力分开天地，并不断撑开、长高
  3. 盘古倒下后，身体各部分化成了世间万物 ✔
  4. 作者想说明斧头比力气更重要

答案: C

第3段反复写「气息／声音／眼睛／四肢……变成……」，中心是盘古化身万物。

错项解析:
A: 那是第1段「混沌／沉睡」的内容。
B: 那是第2段「开天辟地／长高」的内容。
D: 文中没有比较斧头和力气谁更重要。
