单元二巩固⑤：多义字·成语·仿写·修辞·段落大意 · 第 2 关 · 上海小学四年级

多义字：把加点字放回整词里想，不要只记一个常用义。
成语要贴合句子语境，别只挑「认识」的词。
「越……越……」写程度变化；「犹如」后面要接形象的比喻。
比喻常有「像／仿佛／犹如」；拟人是让物做人事。
段落大意抓这一段反复写的中心，别把别段内容硬套进来。

第1题 · 多义字「撑」

「支撑」里加点字「撑」的意思是？

  1. 张开、打开
  2. 顶住、支持使不倒下 ✔
  3. 装满、塞满
  4. 用力推开

答案: B

「支撑」指顶住、支持，使不倒下；盘古用身体把天撑住，就是这个意思。

错项解析:
A: 「撑开」有时有张开的意思，但「支撑」强调的是顶住、支持。
C: 「撑」有时有装满的意思（如「撑破」），这里不是。
D: 「推开」不是「支撑」里「撑」的意思。

第2题 · 成语选用

盘古用尽全身力气把天地分开，从此才有了世界。下面哪个成语最贴合「第一次开辟天地」的意思？

  1. 奔流不息
  2. 精疲力竭
  3. 开天辟地 ✔
  4. 枝繁叶茂

答案: C

「开天辟地」本指盘古开辟天地，也比喻前所未有、开创事业。这里正贴合「第一次开辟天地」。

错项解析:
A: 「奔流不息」写水流不停，不是写开辟天地。
B: 「精疲力竭」写人累到极点，说的是用力后的状态，不是「开辟」本身。
D: 「枝繁叶茂」写草木茂盛，跟开辟天地无关。

第3题 · 仿写相关判断

老师要求仿写「风越刮越大，雨犹如从天上倒下来。」下面哪一句仿写最合适？

  1. 雾越来越浓，远处的山犹如蒙上了一层薄纱。 ✔
  2. 雾很大，山看不清。
  3. 雾浓了，犹如我想回家。
  4. 风大，雨大，雾也大。

答案: A

原句有「越……越……」写变化，又有「犹如」打比方。A 同样有程度变化＋形象比喻。

错项解析:
B: 只有叙述，没有「越……越……」也没有「犹如」。
C: 「犹如」后面应是形象的比喻，不是「我想回家」这种不相关感受。
D: 只是并列现象，没有仿到句式重点。

第4题 · 比喻还是拟人

「云朵像一群绵羊，静静地趴在山腰上。」这句话主要用了什么修辞？

  1. 比喻 ✔
  2. 拟人
  3. 夸张
  4. 排比

答案: A

把云朵比作绵羊，又有「像」，这是比喻。后面「趴」虽像拟人，但整句主要靠「像……」构成比喻。

错项解析:
B: 虽然「趴」有一点拟人味道，但句子的核心是「像一群绵羊」——把一物比作另一物，主修辞是比喻。
C: 没有故意把程度说得过分。
D: 排比要有三个以上结构相似的短语或句子。

第5题 · 画面感·感受

读到「盘古精疲力竭地倒下了，他的身体缓缓变成了大地的一切」，下面哪一句最像「感受」？

  1. 盘古倒下了，身体变成了万物。
  2. 读到这里，我心里又感动又敬佩，觉得盘古太了不起了。 ✔
  3. 这句话有两个「了」字。
  4. 盘古是神话人物。

答案: B

「感受」要写出自己的心情、态度或体会；A 只是复述内容。

错项解析:
A: 这是「看见／读到了什么」，还缺少情感／态度。
C: 这是数用词，不是阅读感受。
D: 这是常识判断，不是感受。

第6题 · 段落大意 ⭐ 挑战题

一篇写盘古的短文：第1段写盘古撑开天地、身体不断长高；第2段写他倒下后，气息变成风云，声音变成雷霆，眼睛变成日月，四肢和身躯变成大地山川。第2段的主要意思是？

  1. 盘古把天撑得越来越高
  2. 盘古倒下后，身体化成了世间万物 ✔
  3. 宇宙一开始像个大鸡蛋
  4. 作者想去爬山

答案: B

第2段反复写「变成……」，核心是盘古化身万物。

错项解析:
A: 那是第1段「撑天」的内容。
C: 那通常是开头写宇宙混沌的内容。
D: 文中没有这个意思。
