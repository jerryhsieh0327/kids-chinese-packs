单元二巩固③：多义字·成语·仿写·修辞·段落大意 · 第 2 关 · 上海小学四年级

多义字：把加点字放回整词里想，不要只记一个常用义。
成语要贴合句子语境，别只挑「认识」的词。
「越……越……」写程度变化；「犹如」后面要接形象的比喻。
比喻常有「像／仿佛／犹如」；拟人是让物做人事。
段落大意抓这一段反复写的中心，别把别段内容硬套进来。

第1题 · 多义字「张」

「张望」里加点字「张」的意思是？

  1. 打开、展开
  2. 看、向远处看 ✔
  3. 夸张、夸大
  4. 量词，一张纸

答案: B

「张望」指向四周或远处看，「张」在这里跟「看」有关。

错项解析:
A: 「张开嘴巴」一类才是打开、展开。
C: 「夸张」才是夸大的意思。
D: 量词「一张」跟「张望」无关。

第2题 · 成语选用

清晨，江面上雾气慢慢散开，阳光照下来，江水闪着金光，奔流不息。下面哪个成语最贴合江水不停流动的样子？

  1. 静如止水
  2. 奔流不息 ✔
  3. 无拘无束
  4. 精疲力竭

答案: B

「奔流不息」就是水流很快、不停地流，正贴合江水一直向前的样子。

错项解析:
A: 「静如止水」形容非常平静，跟奔流相反。
C: 「无拘无束」多形容人自由自在，不是写江水。
D: 「精疲力竭」写人累到极点，跟江水无关。

第3题 · 仿写相关判断

老师要求仿写「风越刮越大，雨犹如从天上倒下来。」下面哪一句仿写最合适？

  1. 雪越下越密，小路犹如一条白色的绸带。 ✔
  2. 下雪了，小路变白了。
  3. 雪很大，犹如我很开心。
  4. 风刮了，雨下了，雪也来了。

答案: A

原句有「越……越……」写变化，又有「犹如」打比方。A 同样有程度变化＋比喻。

错项解析:
B: 只有叙述，没有「越……越……」也没有「犹如」。
C: 「犹如」后面应是形象的比喻，不是「我很开心」这种不相关感受。
D: 只是并列现象，没有仿到句式重点。

第4题 · 比喻还是拟人

「阳光像金色的绸缎，轻轻铺在江面上。」这句话主要用了什么修辞？

  1. 拟人
  2. 比喻 ✔
  3. 夸张
  4. 排比

答案: B

有「像……」，把阳光比作金色绸缎，是比喻。

错项解析:
A: 虽然「铺」有一点动作感，但这句核心是「像……」的比喻；拟人要让物做人事（说话、微笑、不肯等）。
C: 没有故意把程度说得过分。
D: 排比要有三个以上结构相似的短语或句子。

第5题 · 画面感·感受

读到「盘古倒下后，他的气息变成风和云，声音变成雷霆，眼睛变成太阳和月亮」，下面哪一句最像「感受」？

  1. 盘古的身体变成了很多自然景物。
  2. 我觉得盘古好伟大，他的身体成了整个世界，心里又敬佩又感动。 ✔
  3. 这句话有三个顿号。
  4. 盘古是神话人物。

答案: B

「感受」要写出自己的心情、态度或体会；A 只是复述内容。

错项解析:
A: 这是「看见／读到了什么」，还缺少情感／态度。
C: 这是数标点，不是阅读感受。
D: 这是常识判断，不是感受。

第6题 · 段落大意 ⭐ 挑战题

一篇写盘古的短文：第1段写他撑开天地、身体不断长高；第2段写他倒下后，气息变成风云、声音变成雷霆、双眼变成日月、四肢和身躯变成大地的四极和五岳。第2段的主要意思是？

  1. 盘古把天撑得很高
  2. 盘古倒下后，身体化成了世间万物 ✔
  3. 宇宙一开始像个大鸡蛋
  4. 作者害怕打雷

答案: B

第2段反复写「变成……」，核心是盘古倒下后身体化成万物。

错项解析:
A: 那是第1段「撑开／长高」的内容。
C: 那通常是开头段的内容。
D: 文中没有这个意思。
