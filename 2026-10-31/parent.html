单元二巩固：多义字·成语·修辞·画面感 · 第 1 关 · 上海小学四年级

多义字：先读整词，再想加点字在这个词里的意思。
比喻用「像／仿佛／犹如」；拟人是把物当人写（会说话、会高兴）。
画面感「感受」要写作者或你自己的心情／态度，不只复述看到了什么。

第1题 · 多义字「观」

「乐观」里加点字「观」的意思是？

  1. 看
  2. 景象、样子
  3. 对事物的认识或态度 ✔
  4. 观看表演

答案: C

「乐观」指对事情抱积极的态度／看法，「观」＝认识或态度。不是「看」也不是「景象」。

错项解析:
A: 「看」是「走马观花」一类的「观」。
B: 「景象」是「天下奇观」一类的「观」。
D: 题目问的是「乐观」这个词，不是看演出。

第2题 · 多义字「缘」

「只缘」里加点字「缘」的意思是？

  1. 缘故、原因
  2. 因为 ✔
  3. 缘分
  4. 边缘

答案: B

「只缘」常表示「只因为」，「缘」在这里＝因为。

错项解析:
A: 「缘故」是名词；「只缘」里的「缘」作「因为」讲。
C: 「缘分」是「无缘／有缘」一类；「只缘」不是这个意思。
D: 「边缘」跟这个词无关。

第3题 · 成语选用

下雪后，孩子们跑出来玩，快活极了，最适合填哪个成语来形容他们的心情？

  1. 随遇而安
  2. 毫不吝惜
  3. 无拘无束 ✔
  4. 浩浩荡荡

答案: C

「无拘无束」形容自由自在、不受拘束，贴合孩子们玩雪的快活。

错项解析:
A: 「随遇而安」是能适应环境，不强调欢快玩耍。
B: 「毫不吝惜」指不吝啬，跟心情无关。
D: 「浩浩荡荡」多形容声势浩大的队伍或水流。

第4题 · 比喻还是拟人

「孩子们像刚出笼的小鸟一样，快活极了。」这句话主要用了什么修辞？

  1. 拟人
  2. 比喻 ✔
  3. 排比
  4. 夸张

答案: B

有「像……一样」，是把孩子比作小鸟，属于比喻。拟人是让物像人一样做事，这里孩子本来就是人。

错项解析:
A: 孩子已经是人；这句是用「像」把孩子比作小鸟，是比喻。
C: 排比要有三个以上结构相似的短语或句子。
D: 没有故意把程度说得过分夸张。

第5题 · 画面感·感受

读到「雪花纷纷扬扬的，像雾一样轻，被风刮得在天空中打转」，下面哪一句最像「感受」？

  1. 我仿佛看见天空有很多雪花在转。
  2. 雪花很轻、很小，作者很喜欢这雪。 ✔
  3. 佳木斯在黑龙江。
  4. 这句话有八个逗号。

答案: B

「感受」要写出对景物的体会或作者的情感态度；只复述「看见什么」不够。

错项解析:
A: 这是「仿佛看见」的画面，还缺少情感／态度类的感受。
C: 这是注释里的地理知识，不是感受。
D: 这是数标点，不是阅读感受。

第6题 · 段落大意 ⭐ 挑战题

一篇写「五彩池」的文章：第1段讲听说瑶池传说并来到藏龙山；第2段写水池大小和形状。第2段的主要意思是？

  1. 瑶池里住着神仙
  2. 水池的大小和形状 ✔
  3. 五彩池五彩的原因
  4. 作者爱吃柠檬

答案: B

抓段落里反复写的内容：大小、形状（葫芦、镰刀、盘子、莲花等）→ 大意是水池的大小和形状。

错项解析:
A: 那是传说／开头段的内容，不是第2段重点。
C: 「五彩的原因」通常在更后面的段落。
D: 文中没有这个意思。
