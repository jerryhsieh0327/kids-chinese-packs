单元二巩固②：多义字·成语·仿写·修辞·段落大意 · 第 2 关 · 上海小学四年级

多义字：把加点字放回整词里想，不要只记一个常用义。
「越……越……」写程度跟着变化；「犹如」多用来打比方（像……一样）。
比喻常有「像／仿佛／犹如」；拟人是让物做人事（说话、微笑、奔跑当人写）。
段落大意抓这一段反复写的中心，别把别段或全文主题硬套进来。

第1题 · 多义字「绝」

「绝妙」里加点字「绝」的意思是？

  1. 断绝、隔断
  2. 极、非常 ✔
  3. 走不通的路
  4. 气绝、死亡

答案: B

「绝妙」指极其巧妙，「绝」在这里＝极、非常。

错项解析:
A: 「断绝」是「绝交／绝食」一类的「绝」。
C: 「绝路」才是走不通的意思。
D: 「气绝」才跟死亡有关。

第2题 · 成语选用

盘古撑开天地后，精疲力竭，再也动不了。下面哪个成语最贴合他这时的状态？

  1. 生龙活虎
  2. 气喘吁吁
  3. 精疲力竭 ✔
  4. 欢天喜地

答案: C

「精疲力竭」就是精神力气都用尽了，正是盘古开天地后的状态。

错项解析:
A: 「生龙活虎」形容精神饱满，正好相反。
B: 「气喘吁吁」只强调喘气急，程度比「精疲力竭」轻。
D: 「欢天喜地」写开心，跟累无关。

第3题 · 仿写相关判断

老师要求仿写「风越刮越大，雨犹如从天上倒下来。」下面哪一句仿写最合适？

  1. 天越来越黑，路犹如一条安静的黑带子。 ✔
  2. 天黑了，路很长。
  3. 风刮大了，雨下大了，我们也回家了。
  4. 雨很大，犹如我很饿。

答案: A

原句用了「越……越……」写变化，又用「犹如」打比方。A 同样有程度变化＋比喻。

错项解析:
B: 只有叙述，没有「越……越……」也没有「犹如」。
C: 只是并列结果，没有仿到句式重点。
D: 「犹如」后面应是形象的比喻，不是「我很饿」这种不相关感受。

第4题 · 比喻还是拟人

「月亮躲进云里，不肯出来。」这句话主要用了什么修辞？

  1. 比喻
  2. 拟人 ✔
  3. 夸张
  4. 排比

答案: B

月亮被写成会「躲」「不肯」，像人一样有动作和意愿，是拟人。没有「像／仿佛／犹如」。

错项解析:
A: 没有用「像……」把月亮比作别的事物。
C: 没有故意把程度说得过分。
D: 排比要有三个以上结构相似的短语或句子。

第5题 · 画面感·感受

读到「江水奔流不息，在阳光下闪着金光」，下面哪一句最像「感受」？

  1. 江水一直在流，阳光照在水面上。
  2. 我心里也跟着亮起来，觉得这条江又大又有力量。 ✔
  3. 奔流不息是四个字。
  4. 长江在中国。

答案: B

「感受」要写出自己的心情、态度或体会；A 只是复述画面。

错项解析:
A: 这是「看见了什么」，还缺少情感／态度。
C: 这是数汉字，不是阅读感受。
D: 这是地理知识，不是感受。

第6题 · 段落大意 ⭐ 挑战题

一篇写盘古的短文：第1段写宇宙像大鸡蛋、盘古在里面睡；第2段写他醒来后一斧劈开混沌，清气上升成天、浊气下降成地。第2段的主要意思是？

  1. 盘古睡了很久很久
  2. 盘古劈开混沌，天地分开 ✔
  3. 后来盘古的身体变成万物
  4. 作者不喜欢黑暗

答案: B

第2段核心动作是「劈开」以及清气／浊气变成天地，大意就是盘古劈开混沌、天地分开。

错项解析:
A: 那是第1段的内容。
C: 身体变万物通常在更后面的段落。
D: 文中没有这个意思。
