单元二巩固④：多义字·成语·仿写·修辞·段落大意 · 第 2 关 · 上海小学四年级

多义字：把加点字放回整词里想，不要只记一个常用义。
成语要贴合句子语境，别只挑「认识」的词。
「越……越……」写程度变化；「犹如」后面要接形象的比喻。
比喻常有「像／仿佛／犹如」；拟人是让物做人事。
段落大意抓这一段反复写的中心，别把别段内容硬套进来。

第1题 · 多义字「观」

「奇观」里加点字「观」的意思是？

  1. 仔细看
  2. 景象、样子 ✔
  3. 观点、看法
  4. 参观、游览

答案: B

「奇观」指奇特的景象，「观」在这里＝景象、样子。

错项解析:
A: 「观察」才是仔细看的意思。
C: 「观点」才是看法。
D: 「参观」才是去看、游览。

第2题 · 成语选用

春天到了，山上草木长得很茂盛，一眼望去绿油油的。下面哪个成语最贴合草木长得好的样子？

  1. 精疲力竭
  2. 茂盛
  3. 枝繁叶茂 ✔
  4. 奔流不息

答案: C

「枝繁叶茂」形容枝叶又多又密，正贴合草木长得很茂盛的样子。

错项解析:
A: 「精疲力竭」写人累到极点，跟草木无关。
B: 「茂盛」是词语，但题目要选成语；选项里更贴合的是「枝繁叶茂」。
D: 「奔流不息」写水流不停，不是写草木。

第3题 · 仿写相关判断

老师要求仿写「风越刮越大，雨犹如从天上倒下来。」下面哪一句仿写最合适？

  1. 天越来越暗，星光犹如一颗颗小灯。 ✔
  2. 天黑了，有星星。
  3. 天暗了，犹如我很累。
  4. 风大，雨大，天也暗了。

答案: A

原句有「越……越……」写变化，又有「犹如」打比方。A 同样有程度变化＋形象比喻。

错项解析:
B: 只有叙述，没有「越……越……」也没有「犹如」。
C: 「犹如」后面应是形象的比喻，不是「我很累」这种不相关感受。
D: 只是并列现象，没有仿到句式重点。

第4题 · 比喻还是拟人

「小河哼着轻快的歌，绕过山脚向前跑。」这句话主要用了什么修辞？

  1. 比喻
  2. 拟人 ✔
  3. 夸张
  4. 排比

答案: B

小河「哼歌」「向前跑」，是把物当人来写，属于拟人。

错项解析:
A: 没有「像／仿佛／犹如」这类比喻词，也没有把一物比作另一物。
C: 没有故意把程度说得过分。
D: 排比要有三个以上结构相似的短语或句子。

第5题 · 画面感·感受

读到「清晨，江面上雾气慢慢散开，阳光照下来，江水闪着金光」，下面哪一句最像「感受」？

  1. 雾散了，阳光照在江上。
  2. 我觉得这幅清晨的江景好美，心里一下子变得很安静、很舒服。 ✔
  3. 这句话有两个逗号。
  4. 江水是液体。

答案: B

「感受」要写出自己的心情、态度或体会；A 只是复述内容。

错项解析:
A: 这是「看见／读到了什么」，还缺少情感／态度。
C: 这是数标点，不是阅读感受。
D: 这是常识判断，不是感受。

第6题 · 段落大意 ⭐ 挑战题

一篇写盘古的短文：第1段写宇宙像个大鸡蛋，里面漆黑一片；第2段写盘古醒来后用斧头劈开天地，头顶天、脚踏地，身体一天天长高，把天撑得越来越高。第2段的主要意思是？

  1. 宇宙一开始像个大鸡蛋，里面很黑
  2. 盘古劈开天地并不断撑高天空 ✔
  3. 盘古倒下后身体变成了日月山川
  4. 作者喜欢吃鸡蛋

答案: B

第2段反复写「劈开」「头顶天」「长高」「撑高」，核心是盘古开天并撑高天空。

错项解析:
A: 那是第1段开头的内容。
C: 那通常是后面「化身万物」段的内容。
D: 文中没有这个意思。
